# あしたのやること

夜に「明日の準備」の通知が来て、朝に「今日やること」の通知が来る、それだけのシンプルなTODOアプリ（PWA）です。

## 機能

1. 🌙 夜、自分が決めた時間に「明日のやることリストを作りましょう」と通知が来る → タップすると「明日」の入力画面が開く
2. ☀️ 朝、自分が決めた時間に「今日やること」の通知が来る → タップすると今日のリストが開く
3. ✅ やることリストの追加・チェック・削除

やることリストの中身はすべて端末の中（IndexedDB）に保存されます。サーバーには通知の宛先と時刻だけが保存され、リストの内容は送信されません。

## 使い方

1. このリポジトリをGitHub Pagesで公開する（Settings → Pages → Branch: master）
2. スマホのブラウザ（AndroidはChrome推奨）で `https://<ユーザー名>.github.io/badminton-match-maker/todo/` を開く
3. **ホーム画面に追加**する（Android: メニュー →「ホーム画面に追加」/ iPhone: 共有 →「ホーム画面に追加」）
4. 設定タブで「通知を有効にする」を押し、夜と朝の時間を設定する

## 通知の仕組み

通知はサーバー（Supabase）からのWeb Pushで届くため、**アプリを閉じていても設定した時間ぴったりに届きます**。

- Android: ホーム画面に追加すればアプリを閉じていても届きます
- iPhone: iOS 16.4以降で、**ホーム画面に追加したアプリから**通知を有効にすると届きます（Safariのタブのままでは届きません）
- サーバーに障害があった場合でも、アプリを開けば未通知分がその場で表示されます（ローカルの保険つき）

### サーバー構成（Supabaseプロジェクト `daily-todo`）

- `push_subscriptions` テーブル: 通知の宛先（push endpoint）と次回通知日時
- `vapid_config` テーブル: Web Push用のVAPID鍵（service roleのみアクセス可）
- Edge Function `notify`: 期限が来た購読にプッシュを送信し、次回日時を+24時間する
- pg_cron: 毎分 `notify` を呼び出す

通知の中身（リストのプレビュー）は、プッシュを受け取った端末側のService Workerが端末内のデータから組み立てます。サーバーはリストの内容を知りません。

### 注意

- Supabase無料枠のプロジェクトは、約1週間APIアクセスがないと自動休止します。アプリを開くたびにサーバーへ登録更新のアクセスをするので、普通に使っていれば休止しません。もし休止したら、Supabaseダッシュボードから再開（Restore）してください。
