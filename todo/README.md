# あしたのやること

夜に「明日の準備」の通知が来て、朝に「今日やること」の通知が来る、それだけのシンプルなTODOアプリ（PWA）です。

## 機能

1. 🌙 夜、自分が決めた時間に「明日のやることリストを作りましょう」と通知が来る → タップすると「明日」の入力画面が開く
2. ☀️ 朝、自分が決めた時間に「今日やること」の通知が来る → タップすると今日のリストが開く
3. ✅ やることリストの追加・チェック・削除

データはすべて端末の中（IndexedDB）に保存されます。サーバーやアカウントは不要です。

## 使い方

1. このリポジトリをGitHub Pagesで公開する（Settings → Pages → Branch: master）
2. スマホのブラウザ（AndroidはChrome推奨）で `https://<ユーザー名>.github.io/badminton-match-maker/todo/` を開く
3. **ホーム画面に追加**する（Android: メニュー →「ホーム画面に追加」/ iPhone: 共有 →「ホーム画面に追加」）
4. 設定タブで「通知を有効にする」を押し、夜と朝の時間を設定する

## 通知についての注意

このアプリはサーバーを持たない仕組みのため、通知はブラウザ／アプリが動いている間に届きます。

- **Android（ホーム画面に追加した場合）**: アプリを開いている間は時間どおりに届きます。閉じている間はバックグラウンド同期で届きますが、タイミングが数分〜数時間ずれることがあります。
- **iPhone**: アプリ（またはSafariのタブ）を開いている間のみ届きます。
- アプリを開いたときに、まだ出ていない通知があれば必ず表示されます。

時間ぴったりに確実に届けたい場合は、サーバーからのプッシュ通知の仕組みが必要になります（拡張可能です）。
